# 宝贝积分 App · 原型设计文档

> 视觉与交互规范。目标是打造一个 **明亮、亲和、温暖** 的亲子场景工具，让家长愿意每天打开，孩子看着开心。

---

## 1. 视觉调性

| 维度 | 决策 | 理由 |
|------|------|------|
| 整体调性 | 明亮彩色、亲和、温暖 | 目标场景：家长日常使用，孩子旁观也开心 |
| 配色 | 多色但有主调，每个孩子有自己的主题色 | 区分孩子 + 增加专属感 |
| 圆角 | 16dp（卡片）/ 12dp（按钮）/ 24dp（FAB） | 视觉柔和友好 |
| 头像 | Emoji 圆头像（72dp） | 比图片更轻松，零依赖 |
| 数字呈现 | 大字号、半粗体、彩色（正绿负红） | 一眼看出增减 |
| 动效 | 克制（避免过度游戏化） | 工具属性强 |
| 字体 | Material3 默认（中文用系统字体） | 0 成本，效果已不错 |

## 2. 色彩系统

### 2.1 主品牌色

```
Primary:        #5B6EE1   █████  蓝紫（主色，按钮、强调）
PrimaryDark:    #8B97F3   █████  深色模式主色
Secondary:      #FF9F1C   █████  橙黄（FAB、提示）
SecondaryDark:  #FFB951   █████  深色模式次色
```

### 2.2 语义色（积分专用）

```
正分绿（奖励）:   #2E7D32   █████  强绿
负分红（扣减）:   #C62828   █████  强红
中性灰:          #9E9E9E   █████  0 分状态
```

### 2.3 孩子可选主题色（8 色轮盘）

```
🟧 #FF9800 橙        🟪 #E91E63 粉
🟩 #4CAF50 绿        🟦 #2196F3 蓝
🟫 #9C27B0 紫        🟨 #FFEB3B 黄
🟫 #795548 棕        🟦 #00BCD4 青
```

### 2.4 中性背景

```
Light: 背景 #F7F7FB / 表面 #FFFFFF / 表面变体 #E7E8F0
Dark:  背景 #1A1B1F / 表面 #22242A / 表面变体 #2A2C32
```

### 2.5 颜色使用规则

- **积分正负**必须用语义色，不允许用 primary
- **孩子详情页**主色 = `ChildEntity.colorHex`，其他页面用 primary
- **彩色块**最多 3 色同屏，超出会显得杂乱

## 3. 排版系统（Material3）

| 层级 | 用途 | 字号 / 行高 / 字重 |
|------|------|---------------------|
| displayLarge | 详情页大积分 | 48sp / 56sp / Bold |
| displayMedium | 卡片大数字 | 36sp / 44sp / Bold |
| displaySmall | 卡片积分 | 28sp / 36sp / SemiBold |
| headlineLarge | 弹窗标题 | 24sp / 32sp / SemiBold |
| headlineSmall | 空状态标题 | 20sp / 28sp / SemiBold |
| titleLarge | 卡片标题 | 18sp / 26sp / SemiBold |
| titleMedium | 列表项标题 | 16sp / 24sp / Medium |
| bodyLarge | 正文 | 16sp / 24sp / Normal |
| bodyMedium | 次要正文 | 14sp / 20sp / Normal |
| bodySmall | 辅助说明 | 12sp / 16sp / Normal |
| labelMedium | 标签 | 12sp / 16sp / Medium |
| labelSmall | 极小标签 | 11sp / 14sp / Medium |

**字重规则**：
- 大数字 / 重要标题 → Bold
- 卡片标题 → SemiBold
- 普通文字 → Normal（不显粗，避免视觉混乱）

## 4. 间距系统

```
0  dp   ─  无
4  dp   ─  紧凑（标签内边距）
8  dp   ─  小组件内边距
12 dp   ─  列表项间距 / 按钮内边距
16 dp   ─  卡片外边距（标准）
20 dp   ─  卡片内边距（标准）
24 dp   ─  段落间距
32 dp   ─  大间距（空状态）
48 dp   ─  极端间距
```

**规则**：横向间距统一 `16dp` 起步，纵向根据内容疏密从 `8dp` 起步。

## 5. 组件库

### 5.1 按钮

| 类型 | 用途 | 样式 |
|------|------|------|
| `Button` | 主操作（保存、确认） | 圆角 12dp，padding 14dp，文字 SemiBold |
| `OutlinedButton` | 次要操作（调整分数） | 圆角 12dp，边框 1dp |
| `TextButton` | 取消/链接 | 无背景，hover 显示 |
| `ExtendedFloatingActionButton` | 主要 FAB（记一笔） | 圆角 24dp，左 icon 右文字 |
| `FloatingActionButton` | 次要 FAB（详情页 +） | 圆角 16dp |

### 5.2 卡片

| 变体 | 用途 | 样式 |
|------|------|------|
| `ElevatedCard` | 孩子卡、统计卡 | 圆角 16dp，elevation 2dp |
| `OutlinedCard` | 流水项 | 圆角 12dp，elevation 1dp |
| `FilledCard` | summary 头 | 圆角 16dp，自定义背景色（孩子色 + 8% alpha） |

### 5.3 头部（TopAppBar）

| 类型 | 用途 | 样式 |
|------|------|------|
| 标准 TopAppBar | 首页、列表 | 默认 primary 容器色 |
| LargeTopAppBar | 详情页 | 滚动时缩小，含返回按钮 |
| 沉浸式 TopAppBar | 详情页头 | 背景色 = 孩子色 10% alpha |

### 5.4 输入框

- `OutlinedTextField`：圆角 12dp，焦点时边框变 primary
- 数字输入框：`keyboardType = Number`，字号放大到 headlineSmall
- 标题输入框：单行，限 40 字符
- 备注输入框：2-4 行

### 5.5 列表项

- 流水项：左 icon（+ 或 - 圆点）/ 中标题+副标题+时间 / 右分数（彩色大字号）
- 点击删除（长按弹确认对话框）

### 5.6 空状态

- 大图标（96dp，primary 色）
- 标题（headlineSmall）
- 副标题（bodyMedium，onSurfaceVariant）
- 主操作按钮（如"添加第一个孩子"）

## 7. 交互流程

### 7.1 首次启动（空状态）

```
App 启动
  └→ HomeScreen
      └→ 无孩子 → EmptyState
          └→ 点击"添加孩子" → ChildEditorDialog（弹窗）
              └→ 选头像 + 选色 + 输入姓名 → 保存
                  └→ 关闭弹窗 → HomeScreen 显示新卡片
```

### 7.2 记一笔完整路径

```
HomeScreen 点"记一笔"
  └→ AddRecordScreen（默认选第一个孩子，迭代 2 弹孩子选择器）
      ├→ 选类型（奖励/扣减）
      ├→ 输入/调整分数
      ├→ 输入标题（必填）
      ├→ 可选：填备注
      └→ 点"保存奖励/扣减"
          └→ 写入 Room → 触发 Flow
              └→ 自动返回 ChildDetail，积分已更新
                  └→ HomeScreen 卡片数字也实时更新
```

### 7.3 删除流水

```
ChildDetailScreen 长按某条流水
  └→ AlertDialog "删除这条记录？"
      └→ 二次确认 → Room.delete → 触发 Flow
          └→ 列表自动移除该项，积分自动回退
```

### 7.4 主题切换

```
设置（迭代 4）→ 主题模式
  └→ DataStore 持久化
      └→ App 重启后 JifenTheme 读取并应用
```

## 8. 动效（克制原则）

| 场景 | 动效 | 时长 |
|------|------|------|
| 卡片点击 | Material3 标准 ripple | 200ms |
| 页面切换 | Navigation Compose 默认 fade | 300ms |
| 积分变化 | 数字淡入新值（避免剧烈缩放） | 200ms |
| FAB 显示/隐藏 | 默认 scale | 200ms |
| 弹窗进出 | Material3 AlertDialog 默认 | 150ms |

**不做**：金币飞溅、撒花、震动等过度游戏化效果（保留工具属性）。

---

## 9. 无障碍 / 适配

- 所有图标按钮加 `contentDescription`
- 颜色对比度满足 WCAG AA（深色模式同样）
- 支持系统字号缩放（用 sp 单位）
- 触达目标 ≥ 48dp
- 横屏：HomeScreen 网格列数自适应（min 160dp），其他页面竖排
